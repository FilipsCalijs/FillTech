# IR& Grāmatvedības birojs — лендинг

Лендинг для бухгалтерского бюро IR.GRĀMATVEDĪBAS BIROJS SIA (Латвия). Трафик из Meta Ads, цель — заявка на бесплатную консультацию.

## Работаем по шагам, не одним промптом
Каждый шаг — отдельный файл в `prompts/`. Выполняй только тот шаг, который тебе дали. В конце шага:
1. сохрани результат в указанный файл,
2. коротко отчитайся (что сделано, что решить),
3. **СТОП** — жди «ок» или правок. Следующий шаг не начинай сам.

Порядок: 00-setup → 01-foundation-nav-hero → 02-relief → 03-signature → 04-process-trust → 05-faq → 06-form → 07-footer-mobile → 08-review → 09-ship.
Структура страницы и что берём/не берём из конкурентов — `research/synthesis.md` (уже решено, не переоткрывать).
Визуальный референс клиента — houseofbookkeepers.com (тёмное ↔ светлое, один зелёный акцент).
Прогресс отмечай в `PROGRESS.md` (шаг, дата, итог, открытые вопросы).

## Источники правды (читать перед любым шагом)
- `PRODUCT.md` — продукт, аудитория, факты, ограничения (формат impeccable).
- `DESIGN.md` — визуальная система (появится на шаге 01, часть A; до этого не выдумывать стиль).
- `client/` — ad copy трёх кампаний и методичка агентства Sharpify (офферы, BLVTL).
- `research/` — `competitors.md` (разбор конкурентов из Claude in Chrome), `ui-toolkit.md`, `synthesis.md`.
- `decisions.md` — решения после grill-сессии.

## Жёсткие правила
- Язык сайта — латышский. Шрифты обязаны поддерживать ā č ē ģ ī ķ ļ ņ š ū ž (проверка строкой «Gada pārskats, VID vēstule, grāmatvedība, Ķekava, Ļoti»).
- Факты не выдумывать. Разрешено только то, что есть в PRODUCT.md → Evidence on Hand. Отзывы, цифры клиентов, логотипы — только явные плейсхолдеры `[TODO: …]`.
- В видимых текстах сайта не использовать длинные тире (— и –).
- Анти-AI-сток: не использовать дефолты из frontend-design §calibration и детекторы impeccable (фиолетовые градиенты, glassmorphism, 3 одинаковые карточки, hero-бейдж + 2 кнопки, CAPS-eyebrow над каждым заголовком, «01/02/03» без реальной последовательности, акцент одного слова курсивом, кремовый фон + serif + терракота, чёрный + кислотный акцент, fade-up на каждой секции, count-up цифры, «→» на каждой ссылке, стоковые люди, фейковые логотипы).
- Одна signature-фишка на страницу, всё вокруг спокойное.
- Проверять глазами: после крупных изменений скриншоты Playwright 390 / 768 / 1440 и критика по ним.
- Производительность: LCP < 2.5 s (mobile 4G), CLS < 0.05, начальный JS < 150 KB без ленивого 3D; `prefers-reduced-motion` уважать всегда.
- Секреты (webhook URL, Pixel ID) — только через `.env`, не коммитить.
