## Часть B — Проект, Nav, Hero
1. Инициализируй проект по стеку, подключи токены из DESIGN.md. Никаких дефолтных тем.
2. **Nav:** логотип-текст «IR& Grāmatvedības birojs» (лого `[TODO]`), телефон и WhatsApp `[TODO]`, кнопка «Bezmaksas konsultācija» (ведёт к форме). Минимум пунктов. На мобильном: логотип + иконка телефона + CTA, без бургера, если пунктов ≤ 3. Шапка может уплотняться при скролле — без эффектов стекла.
3. **Hero:**
   - Заголовок крупно (clamp): «Nākamais gads nesakārtos iepriekšējo.»
   - Подзаголовок (≤ 20 слов, только факты): про kavētos gada pārskatus, VID vēstules, bezmaksas konsultāciju, attālināti visā Latvijā.
   - Основная CTA → форма; рядом/ниже — **выбор ситуации** из 4 вариантов строками или сегментом (не сетка карточек с иконками): «Kavēts gada pārskats», «Saņēmu VID vēstuli», «Nav kārtots 1–3 gadus», «Grāmatvedis pazuda». Выбор сохраняется и предзаполнит шаг 1 формы.
   - Визуал справа (на мобильном — под текстом): **карточка «Jūsu SIA statuss»** по мотивам HOB «After cleanup»: строки вроде «Gada pārskats 2024 — nav iesniegts → ✓ Iesniegts», «VID vēstule — neatbildēta → ✓ Atbildēta», «Dokumenti — dažādās vietās → ✓ Vienā mapē». Состояние меняется в ответ на выбор ситуации (короткий переход, это отклик на действие). Значения — иллюстрация процесса, не обещание сроков и не выдуманные цифры.
   - Факты доверия (7 gadu pieredze, attālināti visā Latvijā, dokumenti tiešsaistē) — НЕ строкой через «·». Найди другую подачу или перенеси в секцию доверия.
   - Без 3D в первом экране. LCP-элемент — заголовок.
4. Тексты: латышский, на «Tu», без длинных тире, без «Uzzini vairāk»-пустоты; кнопки называют действие.
