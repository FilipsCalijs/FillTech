# Шаг 03 — Signature: «Čeku kalns nav biznesa plāns.»

Скиллы: threejs, build-threejs-scroll-worlds (только нужные части), gsap-scrolltrigger, gsap-performance. Это **единственная** оркестрованная сцена на странице.
1. Сцена (pin на 2–3 экрана скролла): куча чеков, счетов и конвертов VID → разлетаются → сортируются по годам (2023, 2024, 2025) → ложатся в папку → папка закрывается → штамп «IESNIEGTS» (зелёный акцент). 3 короткие подписи этапов на латышском = «Tagad → Pēc».
2. Процедурно: instanced плоскости с бумажной текстурой (генерировать canvas-текстуру со строками/суммами, без реальных данных), папка из простой геометрии. Без моделей Blender в v1.
3. Производительность: загрузка после LCP (IntersectionObserver), DPR ≤ 1.5, пауза вне экрана, бюджет < 200 KB gzip для чанка сцены. Замеры в PROGRESS.md.
4. Фолбэк для мобильного (< 768 px или слабое устройство) и `prefers-reduced-motion`: переключатель «Tagad / Pēc» (Bench-подход) с двумя статичными кадрами — без WebGL.
5. Остальная страница не получает новых анимаций в этом шаге.
6. `/impeccable animate` для ревью движения, видео/скрины состояний, анти-слоп чек. СТОП.
